# 基线历史（history）

基线换掉之后，**旧版要留在这里**。原因只有一句：

> 基线换了却不留旧版，等于把「为什么变了」永久丢失。

`git log` 里当然查得到，但要回答「这次差异到底是不是我以为的那几处」时，
需要把**新旧两份快照同时摊开**逐项比对（`compare.py --base <旧> --after <新>`）。
只靠 git 历史，得先 checkout 到某个提交、或者 `git show` 到临时文件，容易出错也容易偷懒跳过。

## 命名规则

```
<快照名>.<旧版基线记录的 commit 前缀>.json
```

例：`desktop-baseline.d16ec95.json` = T03-C2 之前的桌面基线（`meta.commit` 就是 `d16ec95`）。

## 什么时候必须存

| 变化 | 是否存档 |
| --- | --- |
| 素材变了（照片增删、字节变） | ✅ 必存 |
| 代码改动导致可观测行为变了（如 T03-C2 让 8 张短横 EXIF 归位） | ✅ 必存 |
| 只是重拍一次快照、内容 0 差异（如双跑复验） | ❌ 不存 |
